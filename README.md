# ISP Monitoring — GitHub-only edition

A static GitHub Pages dashboard backed by JSON snapshots generated by GitHub Actions. The repository contains working software components and simulated tests; it is not yet a production-ready private NMS.

## Architecture
- **Frontend:** static HTML, CSS and ES modules in `frontend/`.
- **Scanner:** Node.js modules in `backend/`, executed by GitHub-hosted Actions.
- **Configuration:** repository Actions secret `ISP_DEVICES_JSON`; never commit credentials.
- **State:** JSON snapshot in `data/devices-status.json` and daily history under `data/history/`.
- **Hosting:** GitHub Pages deployment workflow.

## Implemented software
- MikroTik adapter for system resources, PPPoE sessions, interfaces and simple queues.
- OLT SNMP system query and configurable ONU inventory walk. Exact vendor/model/firmware OIDs must be supplied; the system does not invent OIDs.
- Snapshot schema validation, telemetry normalization, topology graph, analytics, alert transitions and Telegram notifier.
- Historical index generation, dashboard topology controls and historical analytics panels.
- Device onboarding configuration form with OID syntax checks and secret JSON download.
- Automated Node.js tests and GitHub Actions syntax/snapshot validation.

## Device onboarding
Open the deployed **Add Device** page. It validates configuration and downloads a JSON payload. It does not connect to hardware or write to GitHub. Store the payload only in repository Settings → Secrets and variables → Actions as `ISP_DEVICES_JSON`, then run **GitHub-Only On-Demand ISP Scanner** from Actions.

The OLT discovery OID must match the exact vendor/model/firmware MIB. Optional status/RX/TX OIDs and divisors must also be verified. A successful form validation is not a network test.

## Critical privacy and network boundaries
- This repository and its GitHub Pages site are public. Committed snapshots/history can expose device addresses, PPPoE usernames/IPs, topology and alert details. **Do not publish real customer data while the repository is public.**
- The login page is intentionally disabled; static GitHub Pages has no server-side authentication. Do not enter credentials into a frontend-only login form.
- GitHub Pages is read-only. Never put a GitHub PAT or device credential in browser JavaScript.
- GitHub-hosted runners generally cannot reach private RFC1918 ISP addresses. Real private-network polling is not verified in this architecture.
- No real MikroTik/OLT hardware scan has been run as part of the software tests. Unit/integration tests use simulated samples.

## Validation
Run from the repository root:
    npm test
    npm run validate
