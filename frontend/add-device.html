Open scanner workflow

Activation sequence

  1. Validate and download the configuration JSON.
  2. Save its contents as repository Actions secret ISP_DEVICES_JSON.
  3. Open Actions → GitHub-Only On-Demand ISP Scanner → Run workflow.
  4. Review scan logs and the published device snapshot.

Form validation checks configuration syntax only. It does not test network reachability. A completed scanner run is required to confirm a live device connection. GitHub-hosted runners cannot normally reach private ISP addresses.
