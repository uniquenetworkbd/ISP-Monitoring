Activation sequence

  1. Download the validated JSON configuration.
  2. Add its contents as repository Actions secret ISP_DEVICES_JSON.
  3. Open the scanner workflow and select Run workflow.
  4. Review the run logs and the published device snapshot.

A successful form validation is not a connection test. Hardware reachability is only established by a completed scanner run.
