System & workflow settings

This GitHub Pages site cannot securely save repository settings, secrets, or workflow schedules. The previous mock credential fields have been removed.

1. Device credentials

Manage scanner configuration in the repository Actions secret store.

  1. Open repository Settings → Secrets and variables → Actions.
  2. Create or update ISP_DEVICES_JSON.
  3. Never place device passwords or SNMP communities in frontend code or committed JSON.
Open Actions secrets settings ↗

2. Scanner execution

Run the GitHub-hosted scanner manually and review its job logs. No automatic 5/15/30-minute scan schedule is configured by this page.

Open scanner workflow ↗

3. Notifications

Telegram notifications are optional and require repository Actions secrets TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID.

The frontend cannot read or verify these secret values. Delivery is confirmed only by a scanner workflow run with a matching alert condition.

4. Privacy and access status

Public repository warning: committed snapshots, history, usernames, IP addresses, topology and alert details may be publicly readable.

Do not run a real customer-data scan or publish customer identifiers while the repository remains public. Make the repository/data path private or implement a verified data-minimization architecture first. This page does not provide authentication.
